# Spice Route Kitchen — Admin Panel

Static HTML/CSS/JS staff admin panel: menu and category management,
promo banners, user management, and Google sign-in via Firebase Auth
(staff accounts only).

## Related repositories

- Backend API: https://github.com/amitava121/food_delivery_backend
- Customer website: https://github.com/amitava121/food_delivery_website

## Configuration

`api.js` — set `BASE` to the backend URL (default `http://localhost:8000`).

## Run

Serve this folder with any static server:

```bash
python3 -m http.server 3001
```

Then open http://localhost:3001
